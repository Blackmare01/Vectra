Status is not connected to the bot process

Deployment

This page is hosted by Vercel. The Discord bot process must run separately on a persistent Python host.

Prefix

Bot prefix: -!

Commands: -!kick, -!ban, -!mute, -!time.

Token configuration

Set DISCORD_TOKEN in the bot host's private Environment Variables settings.

For local testing, copy .env.example to .env and add your token there.

Security notice

Do not paste your bot token into this webpage or commit it to GitHub. This static dashboard cannot securely write Vercel environment variables or start a persistent Discord gateway connection.
