DEPLOYMENT · GET STARTED

Connect Vectra

Deploy the dashboard on Vercel and run the bot on a persistent Python host.

1 · Create the Discord application

DISCORD

Create an application and bot at the Discord Developer Portal. Invite with bot and applications.commands scopes. Enable Server Members Intent and Message Content Intent.

!
Place Vectra's role above the roles it needs to manage. Give access only to the channels where it should log or create tickets.

2 · Run the bot process

PYTHON 3.10+

Use a persistent worker such as Railway, Render, or a VPS. Keep vectra.sqlite3 on a persistent disk or back it up; it stores warnings and per-server settings.

3 · Host this dashboard

VERCEL

Import the GitHub repository into Vercel. The static site is served from public/; no token or secret is needed on Vercel for this informational dashboard.

Vercel hosts the HTML dashboard. The Python bot must stay on a separate always-on service to receive Discord events.

4 · Configure server logs

IN DISCORD

After inviting Vectra, use Discord's slash commands as a server manager.

ⓘ
Hosting note. Vercel Functions are short lived and cannot maintain a Discord gateway session. This dashboard does not perform Discord OAuth or directly mutate a live guild; all bot configuration is applied through permission-checked Discord slash commands.
